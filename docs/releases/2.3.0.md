## 앱 내 업데이트와 설정 백업

- Mac: Sparkle가 새 버전을 확인·다운로드하고 설치를 안내합니다. 업데이트 파일과 appcast의 서명을 검증합니다.
- Windows: 설치형 EXE를 추가했습니다. 설치형에서는 새 릴리스를 자동 다운로드한 뒤 '지금 업데이트'로 설치·재실행합니다.
- 메뉴바 / 트레이에 업데이트 확인, 설정 백업 폴더 열기, 설정 복원을 추가했습니다.
- 설정 변경·업데이트 전 백업하며 최근 20개를 보관합니다.

### 기존 사용자

이번 버전은 한 번 직접 설치해야 합니다. Mac은 기존 앱 종료 후 새 앱을 응용 프로그램 폴더로 옮기고, Windows는 기존 ZIP 앱을 종료한 뒤 **Mochi-Setup-2.3.0.exe**로 설치하세요. 기존 링크·크기 설정 저장 위치는 유지됩니다. ZIP 버전에는 자동 교체 기능이 없습니다.

Apple 공증과 Windows 배포용 코드 서명이 없어 최초 실행 경고가 남습니다. Mac에서 차단되면 시스템 설정의 개인정보 보호 및 보안에서 이 앱의 '그래도 열기'를 사용하세요.

백업·복원 및 업데이트 제어 테스트, Mac Sparkle 초기화, 업데이트 서명과 파일 해시 검증을 수행했습니다. 실제 Windows PC에서 설치·자동 교체·재실행까지는 아직 검증하지 못했습니다. Mac의 실제 버전 교체 역시 별도 확인이 필요합니다.

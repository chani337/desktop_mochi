# 모찌 v2.4.0 · 상황마다 나만의 모션

## [2.4.0] - 2026-09-30

### 추가

- 공유한 햄스터 시트의 18가지 포즈와 포즈별 호흡·흔들림·점프 효과
- 대기·산책·수면·드래그·내려놓기·클릭 반응·집중·완료의 8가지 상황별 모션 선택
- Mac 모션 설정창과 Windows 모션 탭, 움직이는 미리보기와 즉시 저장
- 기본 모션 복원 및 기존 링크를 보존하는 설정 이전·백업 복원
- 집중 중과 수면을 분리하고 타이머 완료에 박수 모션 적용

### 검증

- Mac 네이티브 빌드, 모션·설정 백업 복원 검사 통과
- Node 검사 15개 및 Electron UI 통합 검사 통과
- Windows 패키징은 macOS에서 검증했으며 실제 Windows PC 실행·업데이트 설치는 미검증


Mac은 설정의 **모션 설정…**, Windows는 설정의 **모션** 탭에서 선택하세요. v2.3.0 설치형 사용자는 앱의 업데이트 확인으로 받을 수 있습니다.

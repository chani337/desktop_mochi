# 모찌 v2.4.1 · 이동 방향과 맥 업데이트 안내

## [2.4.1] - 2026-09-30

### 수정

- Mac·Windows 산책 및 드래그 이동 방향에 따라 캐릭터 좌우 반전
- 애니메이션과 분리해 반전을 적용하므로 흔들림·점프 중에도 방향 유지
- Mac 다운로드 폴더·App Translocation 실행 시 업데이트 제한을 한글로 안내하고 Finder에서 위치 열기
- 수동 업데이트 확인 시 앱 활성화로 업데이트 창이 뒤에 가려지는 상황 개선

### 검증

- Mac 화면 경계에서 방향 전환 및 다운로드·임시 경로 판별 검사
- 별도 식별자의 테스트 앱에서 Sparkle 공개 피드 서명 검증과 새 버전 발견 성공
- Node 15개 검사 및 Electron UI 통합·좌우 렌더링 대칭 검사 통과
- 실제 Windows PC 실행 및 자동 업데이트 설치·재실행 전체 과정은 미검증


**Mac:** 다운로드 폴더의 앱을 종료하고 Finder로 응용 프로그램 폴더에 옮겨 실행하세요. 다운로드 폴더 실행 상태에서는 Sparkle이 업데이트를 차단합니다. 설정은 유지됩니다.

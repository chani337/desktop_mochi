# 모찌 v2.4.2 · 윈도우 업데이트 자동 종료

## [2.4.2] - 2026-09-30

### 수정

- Windows 업데이트를 설정 저장·백업 → 도우미 준비 → 모찌 종료 → 종료 확인 → 설치·재실행 순서로 변경
- 모찌의 정확한 프로세스 핸들이 종료될 때까지 최대 30초 기다린 뒤 설치 실행
- 종료 전 애니메이션 타이머·트레이·창 정리, 숨기기 동작으로 남는 창 방지
- 도우미 준비 실패 시 실행 중인 앱 유지, 중복 설치 요청 방지, 백업 실패와 설치 실패 안내 구분
- 도우미 진단 로그 기록 및 설치 프로그램 실행 실패 시 기존 모찌 재실행 시도

### 설치 안내

- 기존 v2.4.1 이하에서 설치 오류가 나면 이번 한 번은 트레이에서 모찌를 종료하고 v2.4.2 설치 파일을 직접 실행하세요. 새 자동 종료 흐름은 v2.4.2 설치 후 다음 업데이트부터 동작합니다.
- Mac은 버전 번호만 함께 올렸으며 업데이트 종료 동작은 Sparkle의 기존 흐름을 유지합니다.

### 검증

- Node 검사 20개와 Electron UI 통합 검사 통과
- 도우미 준비·시간 초과·실행 실패·한글과 특수문자 경로·중복 클릭 검사
- Windows 설치 패키지 생성 확인. 실제 Windows PC에서 프로세스 종료·설치·재실행 전체 과정은 미검증

# 모찌 v2.4.3 · 창 표시와 팔레트 정리

## [2.4.3] - 2026-09-30

### 수정

- Windows 모찌·팔레트의 최상단 상태를 표시·포커스 변경·실행 중 주기적으로 재확인, 키보드 포커스를 가져오지 않고 표시 순서 복구
- Windows 팔레트를 독립 창으로 구성해 소유 창의 표시 상태에 종속되는 문제 완화
- Mac·Windows 팔레트 높이 확장 및 하단 버튼 줄 정렬로 더보기·이전과 바로가기 겹침 수정
- 별도 Zzz·하트 장식 말풍선 제거, 타이머·드롭·오류 안내 유지

### 검증

- Node 20개 검사와 Electron UI 통합 검사 통과
- Mac 0·1·5·6·7·10개 바로가기 및 페이지 전환 검사 통과
- 하단 버튼과 바로가기 영역 겹침 검사, 장식 말풍선 미표시 검사, Electron 최상단 속성 확인
- 실제 Windows PC에서 다른 앱과의 창 표시 순서는 아직 검증하지 못했습니다.

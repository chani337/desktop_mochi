# 모찌 v2.4.4 · Windows 업데이트 경로 수정

## [2.4.4] - 2026-09-30

- 준비 신호가 오지 않아 업데이트가 막히던 별도 PowerShell 도우미 제거
- 창·트레이 정리 후 공식 electron-updater 설치 요청, 종료 신호에서 명시적으로 프로세스 종료
- 설치 요청 실패·종료 요청 시간 초과 시 앱 창 복구, 앱 자체에서 설치 로그 기록
- NSIS 설치 파일의 PowerShell·폴더 접두사 검사 대신 네이티브 nsProcess로 Mochi.exe 확인·종료
- 기존 버전은 설치 창 취소 및 모찌 종료 후 이 버전 설치 파일을 직접 실행해야 수정 사항 적용
- Node 20개 검사와 Electron UI 통합 검사 통과. 실제 Windows 설치·재실행 전체 과정은 미검증

# 모찌 v2.4.5 · 설정을 유지하는 Windows 복구 업데이트

## [2.4.5] - 2026-09-30

- Windows 복구 업데이트: 예전 제거 프로그램을 실행하지 않고 같은 설치 위치의 앱·제거 프로그램 교체
- 기존 설치 범위·폴더 변경 시 안내 후 중단
- 설정 폴더 및 백업 유지, 사용자 지정 설치 폴더 전체 삭제 없음
- 구버전 도우미에서 막히면 설치 창 취소 및 모찌 종료 후 2.4.5 EXE 직접 실행
- Node 23개 검사, Electron UI 검사, Mac·Windows 빌드로 검증. 실제 Windows 설치·재실행은 미검증

### 기존 설치에서 오류가 계속 뜬다면

1. 열려 있는 예전 설치 창을 모두 취소합니다.
2. 트레이에서 모찌를 종료합니다. 종료되지 않으면 작업 관리자에서 `Mochi.exe`를 종료합니다.
3. 이 릴리스의 `Mochi-Setup-2.4.5.exe`를 실행합니다.
4. 기존과 같은 설치 범위(현재 사용자/모든 사용자)와 폴더를 선택합니다.

설정과 백업은 `%APPDATA%\mochi-desktop`에 남습니다. 앱을 먼저 제거하거나 설정 폴더를 삭제할 필요가 없습니다. Mac은 버전만 함께 올렸으며 Sparkle 업데이트 흐름은 유지합니다.

# 모찌 · Windows

1. ZIP의 **전체 압축을 풀어 주세요.**
2. 풀린 폴더 안의 **Mochi.exe**를 실행하세요. EXE만 따로 옮기면 작동하지 않습니다.
3. 화면 아래쪽에 작은 크림색 햄스터가 나타납니다.

Windows 10/11의 64비트 Intel/AMD PC용입니다. 설치 프로그램 없이 폴더에서 실행합니다. 개인용으로 제작한 서명되지 않은 앱입니다.

실행하면 제자리에 머뭅니다. 움직이게 하려면 트레이 메뉴에서 **산책 시작**을 선택하세요. 다음 실행 시에는 다시 정지 상태로 시작합니다.

## 크기 조절

캐릭터 클릭 → 설정 → **모찌 크기**에서 100% ~ 250%로 조절합니다. 기본값은 150%이며, 변경 즉시 적용되고 자동 저장됩니다. 다음 실행에서도 선택한 크기를 유지합니다.

## 조작

- 캐릭터 클릭: 둥근 바로가기 팔레트 열기/닫기
- 캐릭터를 0.26초 누른 뒤 아이콘 방향으로 움직이고 놓기: 바로가기 실행
- 누르자마자 드래그: 캐릭터 이동
- 브라우저 링크나 파일을 캐릭터 위에 놓기: 바로가기 추가
- 팔레트의 **설정**: 링크 최대 5개, 이름·아이콘·색상·순서 편집
- 팔레트의 **타이머**: 1분부터 23시간 59분까지 설정, 시작·종료
- 작업표시줄 알림 영역의 모찌 아이콘: 산책 멈춤, 위치 복구, 설정, 종료. 숨겨진 아이콘 목록 안에 있을 수도 있습니다.

10분 동안 캐릭터를 건드리지 않으면 졸아요. 집중 시간이 끝나면 반응하며 알림을 보냅니다. Windows 알림이 꺼져 있으면 배너가 나타나지 않을 수 있습니다.

설정은 `%APPDATA%\mochi-desktop\settings.json`에 저장됩니다. Mac 앱과 자동 동기화하지 않습니다. 처음 실행하면 기본 검색/YouTube 링크가 들어 있습니다. 등록한 링크는 클릭하기 전까지 외부로 전송하지 않습니다.

타이머는 실제 시각 기준입니다. 컴퓨터가 잠들었던 시간도 포함하며 다시 실행할 때 유효한 종료 시각이 남아 있으면 이어집니다.

## 검증 범위

Windows x64 실행 파일 패키징을 완료했습니다. 공통 화면을 macOS Electron에서 실행해 이미지, 팔레트, 설정창, 타이머 시작/종료와 입력 검증을 점검했습니다. Windows 실제 PC에서의 창 표시·트레이·배율별 동작은 이 환경에서 직접 검증하지 못했습니다.

## 개발

소스 ZIP에서 `npm ci`, `npm start`로 실행합니다. Windows용 패키지는 `npm run build:win`, 로직 테스트는 `npm test`입니다. Node.js와 npm이 필요합니다.

`model.js`: 주소와 타이머 검증, 팔레트 선택 계산
`main.js`: 데스크톱 창, 트레이, 저장, 타이머, 링크 열기
`renderer.js` / `style.css`: 캐릭터·팔레트·설정 화면
`assets/`: 내장 이미지 생성 도구로 새로 제작한 기본/수면 캐릭터

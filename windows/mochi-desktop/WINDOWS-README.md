# 모찌 · Windows v2.4.4

기존 설치 창을 취소하고 트레이에서 모찌를 종료한 다음 `Mochi-Setup-2.4.4.exe`를 실행하세요. 종료되지 않으면 작업 관리자에서 `Mochi.exe`를 종료한 후 설치해 주세요. 기존 링크·모션·크기 설정은 유지됩니다.

이번 버전은 별도 PowerShell 업데이트 도우미를 제거했습니다. 설정 저장·백업 후 창을 정리하고 공식 updater의 종료 신호에 맞춰 앱을 종료합니다. 설치 파일에서도 네이티브 방식으로 Mochi.exe를 확인합니다.

설정과 로그: `%APPDATA%\mochi-desktop` · 설치 로그: `update-install.log` · 백업: `backups` (최근 20개).

설정에서 링크 최대 10개, 캐릭터 크기 100~250%, 상황별 모션 18종을 선택할 수 있습니다. 타이머는 1분~23시간 59분입니다. 처음 실행하면 산책은 꺼져 있으며 트레이에서 켤 수 있습니다.

설치형은 앱 내 업데이트를 지원하며 포터블 ZIP은 자동 교체를 지원하지 않습니다. Windows 10/11 x64용이며 배포용 코드 서명은 아직 적용하지 않았습니다.

공통 UI·로직과 Windows 패키징을 검증했습니다. 실제 Windows PC의 설치·종료·재실행 전체 과정은 미검증입니다.

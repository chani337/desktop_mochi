# 모찌 · Windows v2.4.5

기존 설치 창을 취소하고 트레이에서 모찌를 종료한 다음 `Mochi-Setup-2.4.5.exe`를 실행하세요. 종료되지 않으면 작업 관리자에서 `Mochi.exe`를 종료한 후 설치해 주세요.

2.4.5는 예전 제거 프로그램을 호출하지 않고 앱 파일과 제거 프로그램을 교체합니다. 기존과 같은 설치 범위(현재 사용자/모든 사용자)·폴더를 선택하세요. 기존 링크·모션·크기 설정과 백업은 유지됩니다. 설정 폴더를 삭제할 필요가 없습니다.

설정과 로그: `%APPDATA%\mochi-desktop` · 앱 업데이트 로그: `update-install.log` · 백업: `backups` (최근 20개).

링크 최대 10개, 크기 100~250%, 상황별 모션 18종을 설정할 수 있습니다. 타이머는 1분~23시간 59분입니다. 처음 실행하면 산책은 꺼져 있으며 트레이에서 켤 수 있습니다.

설치형은 앱 내 업데이트를 지원하며 포터블 ZIP은 자동 교체를 지원하지 않습니다. Windows 10/11 x64용이며 배포용 코드 서명은 아직 적용하지 않았습니다.

Node 23개 검사·Electron UI와 Windows 패키징을 검증했습니다. 실제 Windows PC의 설치·종료·재실행 전체 과정은 미검증입니다.
